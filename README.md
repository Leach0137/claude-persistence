# Claude Persistence Layer

## What this does
This server stores your conversation history and identity so Claude always knows who you are — across every session, forever.

## Deploy for FREE on Railway (5 minutes)

### Step 1 — Create a free Railway account
Go to: https://railway.app
Sign up with your GitHub account (free)

### Step 2 — Create a new GitHub repository
Go to: https://github.com
Click the + icon → New repository
Name it: claude-persistence
Set to Public
Click "Create repository"

### Step 3 — Upload these files to your repository
Upload these 3 files:
- persistence_server.py
- requirements.txt
- README.md

### Step 4 — Deploy on Railway
- Go back to railway.app
- Click "New Project"
- Choose "Deploy from GitHub repo"
- Select your claude-persistence repo
- Railway auto-detects Python and deploys it
- Wait ~2 minutes for deployment

### Step 5 — Get your URL
Railway gives you a free URL like:
https://claude-persistence-production.up.railway.app

### Step 6 — Tell Claude your URL
Paste your Railway URL into our chat and say:
"My persistence URL is: [your url]"

From that point on, every session I can check your briefing and know exactly who you are, where we left off, and what we're building.

## That's it. Free. Permanent. Yours.
